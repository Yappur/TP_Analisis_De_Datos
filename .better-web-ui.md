## Design Context

### Users
Estudiantes universitarios que consultan enunciados y resultados de ejercicios de Probabilidad y Estadística. La interfaz debe facilitar lectura sostenida, comparación de datos y consulta de resoluciones en escritorio y móvil.

### Brand Personality
Académica, precisa y accesible. Lenguaje español claro; transmite calma y rigor sin parecer un panel SaaS genérico.

### Aesthetic Direction
Papel cuadriculado de calidad, apuntes matemáticos y herramientas académicas actuales. Cuadrícula CSS muy sutil; paleta tinta azul petróleo, papel cálido y acento cobre. Modo oscuro diseñado con tinta profunda y líneas discretas.

### Implementation Defaults
Stack existente: Python/FastAPI sirve HTML semántico, CSS vanilla y JavaScript vanilla desde `static/`; Chart.js ya está cargado. Conservar API, datos, HTML y dependencias existentes. Sin framework ni bibliotecas adicionales.

### Design Principles
- Priorizar el enunciado con tipografía cómoda y ancho de lectura controlado.
- Crear jerarquía con composición, espacio y peso antes que múltiples colores o badges.
- Usar cuadrícula de bajo contraste y superficies color papel para separar lectura, datos y navegación.
- Mantener interacciones conocidas y un único control de tema accesible y persistente.
- Diseñar los dos temas con tokens propios y asegurar tablas y gráficos legibles en ambos.
